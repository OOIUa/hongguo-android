# 红果独立安卓端

当前源码版本：**0.5.0**（versionCode 5），支持 Android 8.0（API 26）及以上，沿用既有测试签名。安装包与对应源码见 [GitHub Releases](https://github.com/OOIUa/hongguo-android/releases)，本轮验证和发布进度见 [VALIDATION.md](VALIDATION.md)。

0.1/0.2 版本需先手动覆盖安装支持在线更新的新版；0.3.0 起支持在线更新，0.4.0 起支持两条加速线路。GitHub 无法访问时，可使用发布说明中的加速 APK 链接；已支持加速的应用也可在更新窗口选择线路。签名一致时可覆盖安装，保留设备身份、收藏、观看历史及续播位置。请勿先卸载。

## 运行方式

安装 APK 后可从首页推荐或分类浏览选剧，也可直接搜索剧名，点击结果进入详情，选择集数进入全屏播放器。请求、媒体处理和缓存都在手机本机执行，不需要配置服务器地址或 API key。网络用于访问上游内容源。

底部包含首页、分类、搜索、收藏、我的五个入口。首页的热度精选来自短剧热度排序，最新短剧和漫剧榜单分别显示各自内容；不声称提供个性化推荐。分类支持短剧、漫剧和 AI 剧，筛选维度及选项来自实时上游面板，改完条件点击“应用筛选”，可重置和继续翻页。

详情页及播放器内均可收藏。“我的”集中提供播放历史、系统设置和检查更新。收藏与观看历史在手机本地独立保存，各最多 200 部；支持单条移除、清空确认和继续观看。历史仅在实际渲染首帧后记录，保留集号和集内播放位置，准备失败不会被记作已观看。清空历史不会清空收藏，清空收藏也不会清空历史。

系统设置提供自动连播、下一集预加载、自动检查更新三个本地开关，选择会在本机保存。关闭自动检查后仍可手动检查更新。

## 播放与缓存

全屏播放器上划播放下一集，下划返回上一集；也可打开选集面板直接跳集。支持点画面暂停或继续、拖动进度、收藏和错误重试，返回键回到详情。开启自动连播后，本集结束继续下一集，末集不循环。

0.5.0 对常见的非碎片 CENC MP4 使用 Range 按需取块和本机解密，支持边播边缓存，首帧不必等整集下载完成。仅在媒体不支持此播放路径时，回退到整集下载、处理完成后再播放的兼容方式；不能保证所有编码、MP4 布局或上游服务都支持渐进播放。

下一集预加载仅在应用处于前台、开关开启、当前集已渲染首帧且缓冲达到 5 秒后启动；除索引与样本探测外，额外预热最多 512 KiB 的文件前段。切到后台会停止播放与预加载。渐进缓存与旧的完整缓存各有独立的 512 MiB 额度；不完整的渐进缓存会在会话关闭时清除，缓存也可能按空间策略淘汰。缓存用于播放加速，不作为永久离线保存。

## 在线更新

开启自动检查更新时，应用启动且距上次检查已满 24 小时才会静默检查一次；没有新版或检查失败时不弹窗打扰。在“我的”点击“检查更新”可随时手动检查。发现兼容的更高版本后显示版本与更新说明，点击“下载更新”才开始下载，也可选择“稍后”或取消下载。

下载完成后，应用检查文件大小、SHA-256、包名、versionCode、versionName、最低系统版本及签名证书；点击“安装更新”前还会重新校验。首次安装更新时，系统可能要求允许本应用安装来自此来源的应用，授权返回后继续打开系统安装界面，由用户确认。应用不会静默安装。

更新来源为 [OOIUa/hongguo-android](https://github.com/OOIUa/hongguo-android)，清单固定地址为 [update.json](https://github.com/OOIUa/hongguo-android/releases/latest/download/update.json)。只有更高的 `versionCode` 才视为新版，版本名称仅作显示。清单与更新包通过匿名 HTTPS 下载，APK 不包含 GitHub 凭据。

0.4.0 起，更新清单和 APK 都支持加速。默认“自动切换”依次尝试 GitHub 直连、加速线路 1（gh-proxy.com）及加速线路 2（ghfast.top），连接失败或收到无效内容时切换下一条；取消下载会停止，不会自行重试其他线路。也可在更新窗口指定某条线路，选择会在本机保存。下载开始后暂停切换，取消后可重新选择。代理不改变清单中的 GitHub 原始地址；各条线路都必须通过相同的安装包完整性和签名检查。公共代理仅接收公开发布资源的匿名请求。

当前仍使用既有测试密钥签名。发布者应保留本地同一密钥；公开证书指纹见 [release-signing.sha256](release-signing.sha256)，它不是私钥。若将来换成不同的正式签名，当前安装无法直接被该新签名覆盖，不能承诺保留数据的原位升级；迁移方式需另行说明。

## 构建

安装 JDK 17 或 21、Android SDK Platform 36，并设置 `ANDROID_HOME`；或在本机 `local.properties` 中指定 `sdk.dir`。然后运行：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

产物位于 `app/build/outputs/apk/debug/app-debug.apk`，使用测试签名。发布构建必须核对签名与 [release-signing.sha256](release-signing.sha256) 一致；另一台机器自动生成的测试密钥不能用于覆盖现有安装。发布资产可在提交源码后通过 `pwsh -File scripts/prepare-release.ps1` 生成到 `../dist/`。后续版本的版本参数、清单生成及 GitHub 发布步骤见 [RELEASING.md](RELEASING.md)。

有可用 Android 设备或模拟器时，可运行联网搜索、选集和实际解码测试：

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

联网测试会访问上游真实内容并下载剧集，执行时间和可用性取决于网络和内容源。更新功能的校验测试与真实发布检查结果以 `VALIDATION.md` 为准。

## 代码结构

- `app/src/main/java/com/hongguo/android`：原生界面、发现页与筛选模型、页面状态、收藏历史、更新清单、更新下载与系统安装交接。
- `app/src/main/java/com/hongguo/api`：从历史版本迁移并适配的请求与媒体核心。
- `app/src/main/assets/upstream.json`：公开上游接口参数，无自建服务地址或预置登录凭据。
- `app/src/test`：JVM 核心、筛选分页与更新校验回归测试。
- `app/src/androidTest`：安卓设备验证。

应用无需广泛文件访问权限。缓存及收藏历史保存于应用私有目录；清除应用数据或卸载会删除这些本机数据。此版本仅在前台播放，不提供后台播放服务或批量离线下载。
